### 👤 About Me

I am **Amit Padhan**, a **B.Tech Computer Science & Cybersecurity student** from India with a relentless focus on **Offensive Security**, **Red Teaming**, and **Linux System Internals**. 

I run **Arch Linux** with a heavily customized **Hyprland** tiling window manager and **Kitty** terminal as my primary workstation. I specialize in building custom security monitoring tools ([`linux-eye`](https://github.com/amitpadhan525/linux-eye)), automated recon frameworks ([`ReconX`](https://github.com/amitpadhan525/ReconX)), and architecting isolated **QEMU/KVM** virtualized lab networks.

#### 🎯 Core Technical Focus:
- 🔐 **Offensive Security & Red Teaming**: Pentesting, Web App Security, Active Directory & Windows Exploitation, SMB/NTLM Relay, and CTFs.
- 🐧 **Linux Internals & Systems**: Arch Linux + Hyprland power user, system call monitoring (`psutil`, `inotify`), kernel interfaces, and Python/Bash automation.
- 🧪 **Virtualization & Network Infrastructure**: QEMU/KVM lab setup with bridge interfaces (`br0`), TAP devices, isolated subnets (`192.168.100.x`), TPM 2.0 & VirtIO.
- 🎯 **Active Practice**: Hack The Box (Level 6), TryHackMe (65+ rooms completed), OverTheWire, and PortSwigger Web Security Academy.
