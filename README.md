## 👨‍💻 About Me

I am a B.Tech student with a deep passion for **Offensive Security** and **Vulnerability Analysis**. My journey is driven by a curiosity for how systems work under the hood and how they can be exploited—and secured. I spend my time diving into system internals, writing automation scripts, and exploring the vast world of penetration testing.

- 🔭 **Currently focusing on:** Web Application Security (SQLi, XSS, Auth bypasses) & Linux Privilege Escalation.
- 🐧 **Daily driver:** Arch Linux (because I like building things from the ground up).
- 🥋 **Practicing on:** TryHackMe, OverTheWire, and PortSwigger Web Security Academy.
- 🌱 **Always learning:** Advanced Networking, Packet Analysis, and Exploit Development.
- 🎯 **Career Objective:** To build a strong career in cybersecurity by developing practical expertise in penetration testing, vulnerability assessment, and secure system design.
