### 👤 About Me

I am a **B.Tech Cybersecurity student** and **aspiring Security Engineer** with a passion for offensive security, system internals, and security automation. As a dedicated **Arch Linux** user, I build security utilities, custom virtual labs, and automated tools to analyze low-level system behavior.

* 🔐 **Offensive Security & Pentesting**: Focusing on vulnerability analysis, network exploration, and web application security.
* 🐧 **Linux Internals & Scripting**: Exploring kernel interfaces, system calls, and automating workflows using Python & Bash.
* 🧪 **Virtualization & Security Labs**: Architecting pre-configured lab environments with QEMU/KVM, TPM 2.0, and VirtIO.
* 🤖 **Security Tools & Automation**: Building custom monitoring systems (`linux-eye`) and reconnaissance frameworks (`ReconX`).
* 🎯 **Active Practice & CTFs**: Consistently solving labs on TryHackMe, OverTheWire, and PortSwigger Web Security Academy.
