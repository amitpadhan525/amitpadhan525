### 👤 About Me

I am **Amit Padhan**, a **B.Tech Computer Science & Cybersecurity student** from India, dedicated to mastering offensive security, penetration testing, red teaming, and system internals. I run **Arch Linux** with a custom **Hyprland** setup as my primary environment, building security tooling, automated recon scripts, and custom virtualized lab networks.

- 🔐 **Offensive Security & Red Teaming**: Penetration testing, Web App Security, Active Directory & Windows Security, Network Exploration, and CTF challenges.
- 🐧 **Arch Linux & System Internals**: Arch Linux + Hyprland power user, Kitty terminal, custom Waybar/Rofi tweaks, system calls, and Bash/Python automation.
- 🧪 **Custom Virtualization Lab**: Architected an isolated **QEMU/KVM** lab environment with a dedicated `br0` bridge, custom TAP interfaces, and dynamic subnets (`192.168.100.x`) hosting Kali Linux, Ubuntu, Windows 11, and Metasploitable2.
- 🤖 **Security Tooling**: Developer of [**LinuxEye**](https://github.com/amitpadhan525/linux-eye) (`linux-eye`), a real-time host monitoring system utilizing `psutil`, `inotify`, and multi-threaded event tracking.
- 🎯 **CTF & Lab Platforms**: Active solver on **Hack The Box** (Level 6) & **TryHackMe** (65+ rooms completed), with experience in OverTheWire and PortSwigger Web Security Academy.
